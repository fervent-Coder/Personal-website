# Portfolio

Personal website showcasing my projects, built with React and Vite.

**Live site:** https://fervent-coder.github.io/Personal-website/

## Run locally

```bash
npm install
npm run dev
```

## Deployment

Every push to `main` builds the site and deploys it to GitHub Pages through the
workflow in `.github/workflows/deploy.yml`. The build output (`dist/`) is
generated by the workflow and is not committed to the repo.
